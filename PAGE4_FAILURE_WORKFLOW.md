# Required Live FAIL Workflow

This build intentionally uses the simplified evaluator workflow:

**FAIL → 1 of 5 failure modes → 1 of 5 primary contributors → objective comment if needed → save**

## Step 1 — exactly five failure modes

1. Not performed / incomplete
2. Incorrect technique
3. Timing / sequence
4. Unsafe action
5. Other / unclear

## Step 2 — exactly five primary contributors

1. Knowledge / cue recognition
2. Judgment / prioritization
3. Psychomotor execution
4. Communication / teamwork
5. System / performance context

Legacy detailed categories are not live choices. They are not included in `app.js` as evaluator selections.
